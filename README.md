# Sanket Barapatre portfolio

A static personal site for GitHub Pages. Open `index.html` locally or serve this directory with `python3 -m http.server 8000`.

The page uses HTML, CSS, a small JavaScript view switcher, and original SVG illustrations. No build step or runtime dependencies are required. The platform view is the default; `?view=backend` opens the backend view. Review the public wording before publishing updates.
